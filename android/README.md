# IZLA Android pilot

Устанавливаемый онлайн-клиент для Android 8.0+ (minSdk 26). Java Activity + Android WebView, без сторонних SDK и JavaScript bridge. Открывает только https://izla-production.up.railway.app внутри приложения. Telegram, телефон и email открываются во внешних приложениях.

## Сборка

GitHub Actions → **Build IZLA Android APK** → артефакт **izla-android-apk**. ZIP содержит подписанный тестовый APK и SHA-256. Сборка выполняет `assembleDebug`, `lintDebug`, `apksigner verify` и проверку манифеста. Локально нужны Java 17, Android SDK 35 и Gradle 8.11.1:

```bash
cd android
gradle :app:assembleDebug :app:lintDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

## Установка

Открыть APK на Android, при запросе разрешить установку из того приложения, которым открыт файл. Пакет `uz.izla.app.pilot`, версия `1.0.0-pilot`. Это тестовая подпись, не релиз для Google Play. Ключ debug кешируется между сборками, но при потере кеша для обновления может потребоваться переустановка. Для производственных обновлений нужен собственный постоянный release-ключ, хранящийся вне репозитория.

## Разрешения и ограничения

- Камера запрашивается только при съёмке и предоставляется только origin IZLA; микрофон и файлы не запрашиваются.
- Точное/приблизительное местоположение запрашивается при включении GPS. Фоновое местоположение не запрашивается и не реализовано.
- HTTP запрещён, ошибки TLS не игнорируются, доступ WebView к файлам/контенту отключён.
- Cookie входа сохраняется. Резервное копирование данных Android выключено.
- При отсутствии сети показан экран повторной попытки.
- Нужны интернет и актуальный Android System WebView. Реальные Telegram/MyID/Яндекс подключения зависят от конфигурации сервера; APK их не подменяет.
- APK следует дополнительно проверить на физических устройствах: камера, отказ в разрешении, повторное разрешение, GPS, Telegram, возврат из фона и экранная клавиатура.
